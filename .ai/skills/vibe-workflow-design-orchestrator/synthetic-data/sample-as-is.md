# Sample — As-is (hiện trạng: sắp tài liệu thủ công)

> Use-case: tổ chức tài liệu. Dùng cho BT2 nếu HV chưa kịp mô tả as-is.

## Quy trình: Sắp xếp tài liệu vào folder đúng
**Người:** Quản lý / chiến lược gia · **Tần suất:** 2-3 giờ/tuần

| # | Bước | Người thực hiện | Input | Output | Điểm nghẽn / Lỗi lặp |
|---|------|-----------------|-------|--------|----------------------|
| 1 | Nhận file từ email/Zalo/Drive | Quản lý | File đính kèm | File tải về Downloads | Trộn lẫn nhiều nguồn |
| 2 | Mở file xem nội dung để biết là gì | Quản lý | File | Hiểu loại file | Mất thời gian, file nhiều |
| 3 | Quyết định đặt vào folder nào | Quản lý | Hiểu loại file | Quyết định vị trí | Không có policy rõ → đặt đại |
| 4 | Đổi tên tay theo ý (hoặc không đổi) | Quản lý | File + quyết định | File đã đổi tên | Tên tùy tiện (final_final) |
| 5 | Copy/move file vào folder | Quản lý | File | File ở folder | Hay copy nhầm, trùng |
| 6 | Khi cần tìm → mở lần lượt từng folder | Quản lý | Từ khoá nhớ | File cần | Mất 15-30 phút/lần |

**Thời gian tổng:** ~3 giờ/tuần sắp + ~2 giờ/tuần tìm = **5 giờ/tuần lãng phí.**
