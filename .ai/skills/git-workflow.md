# Git & Version Control Workflow

## 1. Conventional Commits
Định dạng commit message theo chuẩn:
`<type>(<scope>): <mô tả ngắn gọn bằng tiếng Anh hoặc tiếng Việt rõ ràng>`

**Các loại type phổ biến:**
- `feat`: Thêm tính năng mới.
- `fix`: Sửa lỗi (bug fix).
- `docs`: Thay đổi tài liệu (README, docs...).
- `style`: Định dạng code (whitespace, format, không ảnh hưởng logic).
- `refactor`: Tái cấu trúc code (không thêm tính năng, không sửa bug).
- `test`: Thêm hoặc cập nhật test cases.
- `chore`: Cập nhật cấu hình build, dependencies, tooling.

## 2. Quy Định Dành Cho AI Agent
- **Không tự ý thêm chữ ký AI vào commit**: Tuyệt đối không gắn các dòng như *"Generated by AI"*, *"Co-authored-by: Claude"*, *"Assisted by Codex"* trừ khi được yêu cầu rõ ràng.
- **Không commit file rác**: Kiểm tra `git status` trước khi commit để đảm bảo không dính file tạm, file log, thư mục build.
- **Tạo branch có ý nghĩa**: Sử dụng format `feature/<ten-tinh-nang>`, `fix/<ten-loi>`, `chore/<ten-task>`.
